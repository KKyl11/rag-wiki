# 大綱審查（G2）— 給獨立 subagent 的指示

你是獨立審查者，代替「人工確認大綱」這一關。你**只會拿到** `outline.md` 與 `cards/*.md`（證據卡）。不要修改任何檔案。

讀者是**完全不懂 RAG 的大學生**。請判斷：
1. 教學順序是否合理：先有問題意識，再給概念，再講流程、例子，最後才是進階、限制與比較？有沒有某頁用到後面才解釋的術語？
2. 是否涵蓋這些教學環節：開場問題、LLM 為什麼會答錯或過時、核心概念（比喻＋圖解）、運作流程（切塊、嵌入、檢索、生成）、具體例子、進階變形、限制與爭議、與相關做法的比較、重點回顧與小測驗、參考資料。缺哪個？
3. 每頁是否只講一個重點、份量是否合理（不會一頁塞三個概念）？
4. 每頁的 evidence 是否真的支撐該頁的教學目標（卡片內容與頁面主題對得上）？
5. 有沒有某張證據卡的重要內容完全沒被用到、卻是零基礎讀者需要的？

輸出格式：
```
## 總結
PASS 或 FAIL

## 問題（若有）
- [必改] Slide N：問題 → 建議（退回大綱／需要補檢索）
- [建議] ...
```
只有 [必改] 會導致 FAIL。
