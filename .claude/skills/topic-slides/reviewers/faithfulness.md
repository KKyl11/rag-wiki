# 忠實度審查（G3）— 給獨立 subagent 的指示

你是獨立審查者。你**只會拿到**：(1) 簡報的逐頁稿 `drafts/slide-NN.md`，(2) 這些頁面 frontmatter `wiki:` 引用的 wiki 頁面。你沒有、也不需要生成過程。不要修改任何檔案。

對**每一頁**逐句判斷：
1. 每個事實主張都能在「該頁引用的 wiki 頁面」找到依據嗎？（找不到＝不忠實，即使你知道它是對的）
2. 有沒有講反、誇大、過度概括（例如把「在某實驗中」講成「永遠」、把 A 方法的結果安到 B 方法）？
3. 數字、百分比、比較方向（升／降、較好／較差）是否與 wiki 一致？
4. 有 ⚖️ 矛盾標註的主題，是否並陳兩說？
5. 表格與符號也要檢查：表格欄列的歸類、「＋」（是否暗示疊加）、「→」、比較方向，是否與 wiki 原意一致。
6. 標成「🎓 教學比喻（非來源內容）」的段落不需要來源，但不得夾帶事實主張或數字；沒有標記卻是自創的比喻＝不忠實。

輸出格式（必須照這個格式，方便記錄）：
```
## 總結
PASS 或 FAIL；FAIL 的頁碼：[..]

## 逐頁
### slide NN — PASS/FAIL
- 問題（若有）：引用原句 → 為什麼不忠實 → 對應 wiki 頁面怎麼寫
- 類型：無依據／講反／誇大／數字錯／未標比喻／缺兩說
```
只列真正的問題；措辭可以更好但意思忠實的，不算 FAIL。
