# 證據卡：edge2024（GraphRAG）— v2
- E1: 「資料集的主要主題是什麼？」這類全域問題需要理解整個語料，一般 RAG 會失敗。[wiki: concepts/graphrag.md] [src: edge2024, p.1]
- E2: 做法：用 LLM 從文件抽出實體與關係建成知識圖 → 分成階層式群集、由下而上替每個群集寫摘要 → 回答時每份摘要各自產生部分答案（map），再合成最終答案（reduce）。[wiki: concepts/graphrag.md] [src: edge2024, p.2]
- E3: 全面性勝率對 vector RAG 為 72–83%（Podcast）與 72–80%（新聞）；vector RAG 的答案則最直接。〔限定：Podcast／新聞〕[wiki: concepts/graphrag.md] [src: edge2024, p.9]
- E4: 用最高層摘要回答時，比直接摘要原文少用超過 97% 的 tokens。〔限定：最高層摘要〕[wiki: concepts/graphrag.md] [src: edge2024, p.10]
- E5: 這類問題沒有標準答案，因此論文用 LLM 當評審，兩兩比較兩個系統的答案，用「勝率」表示。〔限定：LLM 當評審〕[wiki: concepts/graphrag.md] [src: edge2024, p.2]
