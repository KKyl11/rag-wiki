# 證據卡：edge2024（GraphRAG）
- E1: 一般 RAG 在「資料集的主要主題是什麼？」這類針對整個語料的全域問題上會失敗。[wiki: concepts/graphrag.md] [src: edge2024, p.1]
- E2: 做法：用 LLM 抽出實體與關係建成知識圖 → 分成階層式群集、替每個群集寫摘要 → 每份摘要各自產生部分答案（map），再合成最終答案（reduce）。[wiki: concepts/graphrag.md] [src: edge2024, p.2]
- E3: 全面性勝率對 vector RAG 為 72–83%（Podcast）與 72–80%（新聞）；vector RAG 的答案則最直接。[wiki: concepts/graphrag.md] [src: edge2024, p.9]
- E4: 用最高層摘要回答時，比直接摘要原文少用超過 97% 的 tokens。[wiki: concepts/graphrag.md] [src: edge2024, p.10]
