# 證據卡：asai2023（Self-RAG）
- E1: 傳統 RAG 不管需不需要、段落相不相關，都固定檢索一定數量的段落，可能產生沒幫助的回答。[wiki: sources/asai2023.md] [src: asai2023, p.1]
- E2: Self-RAG 讓模型判斷需要時才檢索，並用批判標記評估自己的輸出、選出最好的一段。[wiki: sources/asai2023.md] [src: asai2023, p.1]
- E3: 四種反思標記：Retrieve（要不要檢索）、ISREL（段落是否相關）、ISSUP（輸出是否被段落支持）、ISUSE（回答是否有用，5 到 1 分）。[wiki: concepts/self-rag.md] [src: asai2023, p.4]
- E4: 7B 與 13B 的 Self-RAG 在開放領域問答、推理、事實查核上勝過 ChatGPT 與加上檢索的 Llama2-chat，長文生成的事實性與引用準確度也明顯提升。[wiki: sources/asai2023.md] [src: asai2023, p.1]
